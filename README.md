# honor_time_bot — کارگزاری به وقت هنر

نسخه چندمنظوره فروش و مدیریت بلیت برای **سینما، تئاتر، موسیقی و رویدادهای فرهنگی**.

## امکانات
- 🎬 سینما، 🎭 تئاتر، 🎵 موسیقی، 🎤 رویداد فرهنگی و سایر برنامه‌ها
- تعریف رویداد و چند سانس برای هر رویداد
- تعریف سالن و نقشه صندلی
- 💺 انتخاب صندلی
- ⏳ رزرو موقت و آزادسازی خودکار
- 💳 چند کارت بانکی و پرداخت کارت‌به‌کارت
- 🧾 دریافت عکس رسید و بررسی توسط مدیر
- ✅ تأیید/❌ رد رسید
- 🎟 صدور کد بلیت اختصاصی
- 📱 آماده برای نمایش QR در مرحله بعد
- 🎁 تخفیف درصدی یا قیمت اختصاصی برای هر کاربر
- 📊 گزارش فروش
- 👨‍💼 چند ادمین
- 🗃️ SQLite

## نصب
```bash
pip install -r requirements.txt
```

متغیرهای محیطی:
```text
BOT_TOKEN=توکن_ربات
ADMIN_IDS=123456789,987654321
HOLD_MINUTES=10
```

سپس:
```bash
python bot.py
```

## نکته
این نسخه بر پایه پروژه قبلی شما ساخته شده، اما مدل «رویداد» را عمومی کرده تا فقط به فیلم محدود نباشد. پرداخت همچنان کارت‌به‌کارت و بررسی رسید توسط مدیر است.
