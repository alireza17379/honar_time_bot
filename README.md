# honor_time_bot — کارگزاری به وقت هنر

ربات فروش بلیت سینما با پرداخت کارت‌به‌کارت، انتخاب صندلی، بررسی رسید توسط مدیر و صدور بلیت دیجیتال.

## امکانات

- 🎬 نمایش فیلم‌های فعال و انتخاب فیلم
- 🕐 نمایش سانس‌های هر فیلم
- 💺 انتخاب صندلی
- ⏳ رزرو موقت صندلی و آزادسازی خودکار پس از پایان زمان رزرو
- 💳 نمایش چند کارت بانکی برای پرداخت
- 💰 محاسبه قیمت پایه بلیت
- 🎁 **تخفیف اختصاصی برای هر کاربر، فقط توسط مدیر**
- 🧾 ارسال عکس رسید کارت‌به‌کارت برای مدیر
- ⏳ قرار گرفتن رسید در وضعیت `pending` تا زمان بررسی
- ✅ تأیید رسید توسط مدیر و صدور بلیت
- ❌ رد رسید توسط مدیر و آزاد شدن صندلی
- 🎟️ صدور کد بلیت اختصاصی
- 📱 تولید QR Code برای بلیت
- 🎟️ نمایش بلیت‌های خریداری‌شده کاربر
- 📊 گزارش تعداد بلیت‌های فروخته‌شده و مبلغ فروش
- 👨‍💼 پشتیبانی از **۳ ادمین**
- 🔐 محدود بودن امکانات مدیریتی به ادمین‌های تعریف‌شده
- 🗃️ ذخیره اطلاعات در SQLite

## پرداخت

در این نسخه **درگاه آنلاین وجود ندارد**.

پرداخت به صورت زیر انجام می‌شود:

1. کاربر فیلم و سانس را انتخاب می‌کند.
2. صندلی موردنظر را انتخاب می‌کند.
3. مبلغ نهایی نمایش داده می‌شود.
4. کاربر یکی از کارت‌های بانکی تعریف‌شده توسط مدیر را انتخاب می‌کند.
5. مبلغ را کارت‌به‌کارت می‌کند.
6. عکس رسید را داخل ربات ارسال می‌کند.
7. رسید برای مدیر ارسال می‌شود.
8. مدیر رسید را بررسی می‌کند.
9. در صورت تأیید، بلیت صادر و QR Code برای کاربر ارسال می‌شود.

## سیستم تخفیف

تخفیف کاملاً در اختیار مدیر است و کاربر امکان تعیین یا تغییر تخفیف را ندارد.

مدیر می‌تواند برای هر کاربر:

- درصد تخفیف تعیین کند؛
- تخفیف را حذف کند؛
- یا حتی یک **قیمت اختصاصی** برای همان کاربر تعیین کند.

مثال:

```text
20
```

یعنی ۲۰٪ تخفیف.

برای حذف تخفیف:

```text
0
```

برای تعیین قیمت اختصاصی:

```text
price:100000
```

## مدیریت

ادمین‌ها از طریق پنل مدیریت می‌توانند:

- 💳 کارت‌های بانکی را اضافه یا حذف کنند.
- 🎬 فیلم اضافه کنند.
- 🕐 سانس ایجاد کنند.
- 💺 صندلی‌های سالن را ایجاد کنند.
- 🎁 برای کاربران تخفیف یا قیمت اختصاصی تعیین کنند.
- 🧾 رسیدهای در انتظار را بررسی کنند.
- ✅ رسید را تأیید کنند.
- ❌ رسید را رد کنند.
- 📊 گزارش فروش را مشاهده کنند.

## تنظیم ادمین‌ها

برای سه ادمین، آیدی عددی تلگرام آن‌ها را در متغیر `ADMIN_IDS` قرار دهید.

نمونه:

```python
ADMIN_IDS = [
    123456789,
    987654321,
    555555555,
]
```

هر سه ادمین به پنل مدیریت دسترسی خواهند داشت.

> برای امنیت بیشتر، آیدی واقعی ادمین‌ها را داخل README عمومی قرار ندهید؛ فقط در تنظیمات محیط اجرا وارد کنید.

## متغیرهای محیطی

قبل از اجرای ربات، این متغیرها باید تنظیم شوند:

```text
BOT_TOKEN=توکن_ربات
ADMIN_IDS=123456789,987654321,555555555
```

`BOT_TOKEN` را داخل کد عمومی GitHub قرار ندهید.

## نصب

ابتدا وابستگی‌ها را نصب کنید:

```bash
pip install -r requirements.txt
```

سپس متغیرهای محیطی را تنظیم کرده و ربات را اجرا کنید:

```bash
python bot.py
```
