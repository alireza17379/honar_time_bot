# 🎨 honor_time_bot — کارگزاری به وقت هنر

نسخه نهایی چندمنظوره فروش بلیت برای:

- 🎬 سینما
- 🎭 تئاتر
- 🎵 موسیقی
- 🎤 رویدادهای فرهنگی
- 🎨 سایر رویدادها

## امکانات

- تعریف رویداد و چند سانس
- تعریف سالن
- ساخت خودکار نقشه صندلی با ردیف و شماره
- انتخاب صندلی
- رزرو موقت و آزادسازی خودکار
- جلوگیری از رزرو همزمان یک صندلی
- پرداخت کارت‌به‌کارت
- چند کارت بانکی
- دریافت عکس رسید
- ارسال رسید برای همه ادمین‌ها
- تأیید یا رد سفارش توسط ادمین
- صدور کد بلیت اختصاصی
- تولید و ارسال QR
- بلیت‌های من
- تخفیف درصدی یا قیمت ثابت برای هر کاربر
- گزارش فروش
- SQLite
- مناسب برای Render Worker / VPS

## نصب

```bash
pip install -r requirements.txt
python bot.py
```

## متغیرهای محیطی

```env
BOT_TOKEN=توکن_ربات
ADMIN_IDS=123456789,987654321
HOLD_MINUTES=10
DB_PATH=honar_time.db
```

## Deploy روی Render

نوع سرویس را **Background Worker** انتخاب کنید.

Build Command:

```bash
pip install -r requirements.txt
```

Start Command:

```bash
python bot.py
```

Environment Variables را تنظیم کنید:

- `BOT_TOKEN`
- `ADMIN_IDS`
- `HOLD_MINUTES`
- `DB_PATH`

> اگر SQLite روی سرویس ابری بدون دیسک دائمی استفاده شود، با ری‌دیپلوی/تعویض نمونه ممکن است اطلاعات از بین برود. برای استفاده واقعی، دیسک دائمی یا PostgreSQL توصیه می‌شود.

## فرمت‌های پنل مدیریت

### افزودن رویداد

```text
نوع | عنوان | توضیحات
```

مثال:

```text
تئاتر | نمایش شازده کوچولو | اجرای ویژه گروه به وقت هنر
```

### افزودن سانس

```text
شناسه رویداد | تاریخ و ساعت | سالن | قیمت
```

### ساخت صندلی

```text
شناسه سانس | تعداد ردیف | تعداد صندلی هر ردیف
```

مثال:

```text
1 | 8 | 10
```

صندلی‌ها با برچسب‌هایی مثل `1-1`, `1-2`, ... ساخته می‌شوند.

### افزودن کارت

```text
نام کارت | شماره کارت
```

### تخفیف کاربر

برای درصد:

```text
123456789 | 20
```

برای قیمت ثابت، عدد را بیشتر از 100 وارد کنید:

```text
123456789 | 150000
```

### پوستر

ابتدا شناسه رویداد را بفرستید و سپس عکس پوستر را ارسال کنید.
