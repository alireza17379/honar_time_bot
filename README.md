# honar_time_bot — کارگزاری به وقت هنر

MVP فروش بلیت سینما با کارت‌به‌کارت.

- چند کارت بانکی با نام بانک از داخل پنل
- قیمت پایه + تخفیف درصدی یا قیمت اختصاصی
- فیلم، سانس، سالن و صندلی
- تا قبل از ارسال رسید، صندلی رزرو نمی‌شود
- بعد از ارسال رسید: pending
- تأیید/رد توسط مدیر
- صدور بلیت و QR Code
- بلیت‌های من و گزارش فروش

## اجرا
```bash
pip install -r requirements.txt
```
سپس:
```text
BOT_TOKEN=توکن BotFather
ADMIN_ID=آیدی عددی مدیر
```
و:
```bash
python bot.py
```

شماره کارت داخل کد نیست و از پنل مدیریت ثبت می‌شود.
